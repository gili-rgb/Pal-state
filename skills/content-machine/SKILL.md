### שלב 0 — Preflight (חובה, לפני כל שלב אחר)

**אל תמשוך דאטה ידנית ואל תבחר נושא. הרץ את הסקריפט.**

```bash
rm -rf /home/claude/pal-gsc /home/claude/pal-state
git clone --depth 1 https://github.com/gili-rgb/pal-gsc-data /home/claude/pal-gsc
git clone --depth 1 https://github.com/gili-rgb/Pal-state /home/claude/pal-state
python3 /home/claude/pal-state/tools/preflight.py --site [csb|marom|plrom] --phase plan
```

הסקריפט מאמת את קיום `pal_lint.py`, קורא את הלדג'ר, טוען את כל שאילתות ה-GSC של האתר, ומחזיר:

| שדה ב-brief | מה זה |
|-------------|-------|
| `allowed_topics` | **הרשימה היחידה שמותר לבחור ממנה** |
| `refresh_queue` | נושאים שמאמר קיים כבר מדורג עליהם 4-20 → Mode Refresh, לא מאמר חדש |
| `brand_hub_gaps` | פער עמוד מותג, לא פער בלוג. אל תכתוב עליהם בלוג |
| `vocabulary` | **אוצר המילים המאומת.** מונח שאינו כאן — אסור להשתמש בו |
| `h1_variants` | הווריאנטים לפי חשיפות. ה-H1 נגזר מהמוביל |

**קריאות MCP הנדרשות** מופיעות ב-`mcp_requests`. בצע אותן, שמור ל-`mcp_results.json` עם המפתחות `live_blog_titles`, `products`, `brand_hub`, `verified_links`, והרץ:

```bash
python3 /home/claude/pal-state/tools/preflight.py --site [site] --phase finalize --mcp mcp_results.json
```

**exit שאינו 0 = עצירה.** אין brief, אין כתיבה. אל תמשיך "בערך".

**מה בוטל בגלל השלב הזה:** שער ה-dedup הידני (ledger + recent_chats + conversation_search + site:) הוחלף בחיסור מכני. אנטי-קניבליזציה מוכרעת לפי מיקום GSC ולא לפי שיפוט. בחירת נושא היא בחירה מרשימה, לא חיפוש.

### שלב 1 — זיהוי פרויקט

קרא את קובץ הפרויקט המתאים. חלץ: מותגים, קישורים אסורים, CTA links, ערוץ YouTube, פרטי ארגון. (נתוני GSC כבר נטענו בשלב 0 מה-repo, ומוצרים/קישורים נמשכים מ-WooCommerce MCP.)

### שלב 2 — בחירת נושא (מתוך ה-brief בלבד)

**אל תחפש נושא. בחר מ-`allowed_topics` שהתקבל בשלב 0.**

הרשימה כבר עברה את כל השערים: הלדג'ר, מיקום ה-GSC של מאמרי בלוג קיימים, וכותרות הבלוג החיות. נושא שאינו ברשימה נפסל מסיבה מתועדת ב-`refresh_queue` או ב-`brand_hub_gaps`.

**כלל הבחירה:** הפריט עם החשיפות הגבוהות ביותר, אלא אם יש סיבה עסקית מפורשת לבחור אחר. דווח את הבחירה ואת הסיבה בשורה אחת, בלי סימן שאלה ובלי המתנה.

**`refresh_queue` = Mode Refresh, לא מאמר חדש.** מאמר בלוג קיים מדורג 4-20 על השאילתה, ולכן יצירת מתחרה תפצל את האות. עדכן את הקיים: תוכן, FAQ מיהלומי Bing, קישורים פנימיים, `dateModified` ו-`.last-updated`. ה-URL נשמר.

**`brand_hub_gaps` = לא נושא בלוג.** שאילתה בלי אות כוונה ("מילה שירות לקוחות", "bsh") היא פער עמוד מותג. העבר ל-brand-hub-machine.

**הבסיס לכך שהחלטת הקניבליזציה היא מיקום ולא חפיפה:** מחקר אהרפס על 80 מילות מפתח עם דירוגים מרובים מצא מקרה אחד שדרש טיפול. חפיפת שאילתות היא ברירת מחדל בריאה באשכול. הסימן לבעיה הוא כוונה זהה ועמוד שכבר מחזיק את המיקום.

### שלב 3 — קישורים פנימיים (מפת קישורים)

בנה מפת קישורים פנימית מלאה לכל מאמר. כל הקישורים נמשכים מ-WooCommerce MCP (שלב 0), **permalink verbatim** (כלל הברזל המלא בשלב 0).

**תקציב קישורים — 4-7 קישורים פנימיים בגוף המאמר:**
1. **קטגוריית אב רלוונטית** — מ-`get_categories` (csb/plrom; **במרום — משדה `categories` בתוצאות `search_products`, לא get_categories**). בחר את הקטגוריה המדויקת לנושא (לא הכי כללית), permalink verbatim. זה צומת ה-hub שמחלק equity.
2. **3 מוצרים** — מ-`search_products` לפי נושא/מותג, קישורים ישירים בגוף.
3. **Hero Product** — כרטיס מוצר (שלב 7).
4. **Cluster** — pillar + 2 siblings (שלב 6).

**⚠️ כלל ברזל — אימות permalink של blog posts (נוסף יוני 2026):**
blog posts אינם במאגר ה-MCP. לכן **אסור לבנות slug מהכותרת** ואסור לסמוך על web_search בלבד.
לכל blog post שמקשרים אליו — חובה להריץ `check_url` (WooCommerce MCP) על ה-URL שנמצא בחיפוש ולחלץ את שדה `canonical`. ה-canonical הוא ה-permalink הנכון. `web_fetch` רק אם `check_url` נכשל (v7.18).

```
# תהליך אימות permalink לכל blog post:
1. web_search → מקבל URL (עשוי להיות percent-encoded)
2. `check_url` על אותו URL
3. חלץ את שדה canonical מה-metadata
4. ה-canonical = permalink שנכנס לבלוג
```

**דוגמה לטעות:** כותרת "מייבש בלומברג תקלות: 7 בעיות נפוצות" → slug שגוי `/מייבש-כביסה-בלומברג-תקלות-7-בעיות-נפוצות/` → canonical בפועל `/מייבש-כביסה-בלומברג-תקלות-7-בעיות-נפוצו/` (וורדפרס חותך slugs ארוכים). בלי אימות canonical — קישור שבור.
